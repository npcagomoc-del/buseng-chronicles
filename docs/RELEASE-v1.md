# Buseng Chronicles — Version 1

Free Filipino meme-inspired rice-throwing game for Android and PC, developed by NPC.

Download **Buseng-Chronicles-v1.0.0.apk** under Assets. Open on Android, allow installation from your chosen browser/file manager if asked, install and play offline. The adjacent SHA-256 file verifies the download. PC players can clone the source and follow the README.

Hold touch/mouse/Space, then release rice onto Buseng's actual green plate. Perfect streaks unlock the close-range slap and flaming chicken-oil rice. Buseng's movement/teleport gets harder with score. Choose Rice Man/Tahp, adjust separate Music/FX volumes, pause with Continue Playing, and retry instantly after a miss.
